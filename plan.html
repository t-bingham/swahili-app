🇰🇷 Korean track + Multi-language platform — Action Plan

Turn the Swahili app into a multi-language platform and add a Korean curriculum, starting with a rule-based Hangul (한글) trainer.
Started: 16 June 2026 · Decisions on record: multi-language in this app (not a fork) · Korean curriculum content LLM-generated with a validation pass · Completed Swahili review work preserved in review/completed-swahili-work.md
Guiding principle. Prove the architecture with a low-risk vertical slice (Stages 1–2) before the big refactor or any generated content. Generate by rule wherever the language is rule-based (Hangul, romanization, conjugation by speech level) — that is exactly what made the Swahili grammar repair reliable. Reserve the LLM for vocab/sentences/cultural notes, and bake a QA pass in from day one. Hard lesson from the Swahili review: LLM curriculum content fails in systematic ways at scale (~4,700 cards were wrong).

Data + scaffolding only. Zero behaviour change to the Swahili app.

Stage 4 · Language-aware behaviour ✓ Done

Make behaviour language-aware — without the risky mass rename.

S4Effort: Med✓ Done
  • pickExercise is language-aware: gated concord & noun-class on the language's feature flags. Grammar tab + onboarding dialect note branch by language (Korean: particles/speech levels/Seoul Standard; no noun-class chart). Migrations tagged sw-only so they never run on Korean.

Stage 5 · Korean curriculum ✓ Starter done

Quality over volume: a curated, correct starter curriculum + the build script to extend it.

S5Content riskEffort: High✓ Starter done
